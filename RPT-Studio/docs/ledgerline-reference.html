Ask the ledger in your own words. The assistant writes the query, shows you the SQL, and runs it only after you approve.

ledgerline — SBO_PROD (HANA)
$ ledger ask "AR over 90 days, top 5 customers"

→ drafted query
SELECT T0."CardCode", T0."CardName",
       SUM(T0."DocTotal" - T0."PaidToDate") AS "Open"
  FROM OINV T0
 WHERE T0."CANCELED" = 'N'
   AND DAYS_BETWEEN(T0."DocDueDate", CURRENT_DATE) > 90
 GROUP BY T0."CardCode", T0."CardName"
 ORDER BY 3 DESC LIMIT 5;
