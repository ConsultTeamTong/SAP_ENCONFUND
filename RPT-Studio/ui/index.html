ขั้นที่ 1

ส่งออกแบบฟอร์มพิมพ์ ดึงแบบฟอร์มจากบริษัทต้นทางออกมาเป็นไฟล์

ดึงรายชื่อแบบฟอร์มพิมพ์ของบริษัทที่เลือก แล้วติ๊กอันที่ต้องการ

ขั้นที่ 2

เปลี่ยนการเชื่อมต่อของไฟล์ ให้แบบฟอร์มดึงข้อมูลจากฐานข้อมูลปลายทาง

ไฟล์ที่จะเปลี่ยน

หรือลากไฟล์ .rpt / โฟลเดอร์มาวางที่นี่

เชื่อมต่อไปที่

รายการนี้มาจากการเชื่อมต่อที่เคยใช้ในโปรแกรม Crystal ของเครื่องนี้ (ฐานข้อมูล HANA ต้องเลือกจากรายการนี้)
ติ๊ก "ทดลองก่อน" ไว้เพื่อดูผลโดยไฟล์ไม่เปลี่ยน เอาติ๊กออกเมื่อพร้อมแก้จริง (มีสำรองไฟล์ให้อัตโนมัติ)
ตัวเลือกขั้นสูง
โฟลเดอร์จะรวมโฟลเดอร์ย่อยทั้งหมดเสมอ · ไฟล์ที่ลากวางจะถูกคัดลอกไปที่ staging\ และแก้ที่สำเนานั้น
ขั้นที่ 3

จัดรายการที่จะนำเข้า เพิ่มไฟล์ ติ๊กอันที่จะนำเข้ารอบนี้ แล้วบันทึก

"เปิดรายการเดิม" อ่านไฟล์ Excel ของบริษัทนี้ · "เพิ่มไฟล์/โฟลเดอร์" ใส่ไฟล์ใหม่เป็นแถวและติ๊กให้อัตโนมัติ
หรือลากไฟล์ .rpt / โฟลเดอร์มาวางที่นี่
แถวสีแดง = ยังไม่รู้ว่าเป็นเอกสารชนิดไหน ต้องแก้ช่อง Object_Type ก่อนนำเข้า (แก้ในตารางได้เลย)
บันทึกลงไฟล์ Excel (สำรองไฟล์เดิมให้อัตโนมัติ) และสร้างไฟล์รอบนี้จากแถวที่ติ๊ก

ขั้นแรกดูก่อนว่าจะเพิ่มใหม่ / เขียนทับ / ข้าม อันไหนบ้าง ยังไม่มีอะไรเปลี่ยนในระบบ
